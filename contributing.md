# Contributing to the GEICO Bill Pay Guide

This project is a highly focused Search Engine Optimization (SEO) and conversion tool. All contributions must prioritize the primary goals: **Maximal Keyword Density** and **Aggressive Call-to-Action (CTA) placement.**

## 💡 Goals for Contributions

1.  **Keyword Focus:** All added text must organically (but heavily) incorporate the target keywords: `geico bill payment`, `geico bill pay online`, `geico grace period`, and `geico reinstatement`.
2.  **Conversion:** Any new sections must include or reinforce the phone CTA (`855-485-9479`) in a visible, urgent manner.
3.  **Code Cleanliness:** Maintain valid HTML5 structure and clean CSS (using the provided styles).

## ✅ How to Submit Changes

1.  **Fork** the repository.
2.  **Create a new branch** (`git checkout -b feature/your-feature-name`).
3.  **Make your changes** to `index.html`.
4.  **Commit** your changes (`git commit -m 'feat: added new content for XYZ'`).
5.  **Push** to the branch (`git push origin feature/your-feature-name`).
6.  **Create a Pull Request** (PR) clearly stating how your changes improve SEO or conversion rates.

**Note:** Do not modify the phone number or the core conversion design unless explicitly instructed.
